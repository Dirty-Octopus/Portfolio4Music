SoundTouchJS
===========

The audio scrubber uses the unmodified @soundtouchjs/audio-worklet package
(version 2.1.1), with @soundtouchjs/core, @soundtouchjs/worklet-base, and
@soundtouchjs/interpolation-strategy-lanczos. These packages are licensed
under the Mozilla Public License, version 2.0.

Source code and package versions:
https://github.com/cutterbl/SoundTouchJS
https://www.npmjs.com/package/@soundtouchjs/audio-worklet/v/2.1.1
See package-lock.json for the exact dependency versions.
