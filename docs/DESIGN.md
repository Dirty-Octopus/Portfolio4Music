# Art direction

Reference: https://www.webdesignmuseum.org/gallery/2advanced-studios-v3-2001

Use V3's restrained blue-gray flats, compact technical typography, separated modules and staged interface assembly, rather than simulated chrome or a modern marketing landing page. All identity art is the supplied Dirty Octopus image, displayed non-destructively through SVG/CSS luminance masks. No generated replacement logo.

Modes: overview, audio archive, visual theater, about; persistent transport. Visual rendering modes (duotone, monochrome, halftone) affect decorative artwork only. Actual playing video retains original colors. System drawer exposes SFX, animation, display treatment, current transport status, and keyboard shortcuts. Motion is state-driven: boot panel assembly, view shutters, category scan reveal, track cartridge change, inspector details, drawer mount/unmount. Respect both system reduced-motion and the in-app motion switch.

Palette: ink #131d24, steel #273844, slate #435764, ice #bacdd5. Accent comes from brightness and typography, not gradients. Barlow Condensed for display and IBM Plex Mono for machine text, bundled locally.
